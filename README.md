# Tablero de mesa · BB Chile

Tablero gráfico para transmitir partidos de Blood Bowl jugados en mesa. Una persona registra lo que pasa y la app lo muestra con los sprites de FUMBBL. No tiene reglas ni IA.

- `index.html`: la app completa (un solo archivo, funciona sin internet).
- Vista de control: la página normal. Botón "Abrir transmisión" abre la vista limpia (`#stream`), que se sincroniza sola.
- Los equipos se guardan en la biblioteca del navegador y se pueden exportar a un archivo.

Proyecto de fans sin fines de lucro. Sprites de FUMBBL usados con atribución a sus autores.
